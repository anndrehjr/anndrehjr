## 🧭 Sobre mim

- 🔭 Atualmente construindo uma **plataforma de documentação de IA** ([ai-docs-hub](https://github.com/anndrehjr/ai-docs-hub)) e evoluindo a **competição gamificada de educação financeira** ([mes-a-mes](https://github.com/anndrehjr/mes-a-mes)), ambas em produção.
- 🤖 Explorando **agentes de IA e RAG local** — construí um tutor de matemática socrático com n8n, um LLM via Groq, busca semântica com embeddings locais e uma ferramenta de álgebra computacional.
- 🏗️ Gosto de arquitetura: já apliquei **Clean Architecture** em .NET, **monorepo** front/back em Node, e **feature-based** em Next.js.
- 🖥️ Administro minha própria infraestrutura: VPS Linux, Docker, Nginx Proxy Manager e Cloudflare — vários sistemas reais em produção simultânea.
- 🎓 Foco recorrente em **sistemas educacionais**: controle de acesso escolar, gestão de salas, banco de questões, planos de aula.
- 🌱 Aprendendo a formalizar melhor testes automatizados (Playwright/Vitest) em todos os projetos, não só nos mais recentes.

## 🏛️ Arquitetura que já apliquei

| Padrão | Onde |
|---|---|
| **Clean Architecture** (camadas API/Application/Domain/Infrastructure) | GestaoProjetos (.NET) |
| **Monorepo** (frontend + backend no mesmo repositório) | mes-a-mes, gerenciador-loja |
| **Feature-based** (conteúdo e rotas organizados por domínio) | ai-docs-hub |
| **Client/Server com API REST** | gerenciador-loja, controle-acesso-escolar |
| **Orientado a eventos/workflow** (triggers, agentes e ferramentas) | Mística (n8n) |
